# Перевод сборки bookmerger на EpubMerge


## Overview

Сохранить скачивание, кэширование, конвертацию FB2, порядок источников, повторы,
именование и атомарную публикацию. Объединение полностью передать EpubMerge. Удалить
собственные титульные и библиографические страницы, сборку оглавления и
переписывание содержимого книг.
Пользователь согласовал EPUB 2.0 и структуру результата EpubMerge вместо гарантий EPUB 3.3.

## Context

- Текущий конвейер: cli.py → скачивание → FB2Converter → stage_epub → build_collection → write_epub → validate_epub
→ публикация.
- Основные файлы: src/bookmerger/{cli,converter,epub,collection,references,validate}.py; tests/; pyproject.toml; uv.lock; README.md;
docs/dependency-decisions.md; .github/workflows/tests.yml.
- EpubMerge предоставляет Python API doMerge. Ядро использует six и стандартную библиотеку; Calibre
для этого вызова не требуется. Оно пишет EPUB 2.0, собирает оглавление из NCX и может
пропускать отсутствующие ресурсы. Поэтому нужны проверки до вызова.
[Исходник](https://github.com/JimmXinu/EpubMerge/blob/main/epubmerge/epubmerge.py).
- Выбран upstream v3.3.0, commit 8cc76632722a94abc2ad08ff0f5cbda83ffb96eb. [Теги](https://github.com/JimmXinu/EpubMerge/tags).
- Подключение: Python-зависимость из архива официального репозитория по полному commit
SHA, зафиксированная в uv.lock. Установку и содержимое wheel необходимо проверить: upstream
setup.py содержит расходящиеся сведения о версии и лицензии. LICENSE и заголовок ядра
указывают GPL v3, setup.py — Apache. [Репозиторий](https://github.com/JimmXinu/EpubMerge),
[setup.py](https://github.com/JimmXinu/EpubMerge/blob/main/setup.py).
- Установленный fbc 1.7.0 поддерживает --to epub2; сейчас проект вызывает --to epub3.

## Границы решения

- FB2 конвертируется непосредственно в EPUB 2 через прежний закреплённый fbc.
- Принимаются EPUB с пригодным NCX. EPUB 3 только с nav отклоняется с понятной ошибкой:
собственный преобразователь nav → NCX в этот переход не входит.
- Внешние ссылки остаются внешними. Автоматическое скачивание изображений и CSS,
упомянутых внутри EPUB, удаляется; автономное чтение гарантируется только для
встроенных ресурсов.
- EPUB 3 с NCX обрабатывается в пределах возможностей EpubMerge. Сохранение специальных
возможностей EPUB 3 и соответствие такого результата всем требованиям EPUB 2 не
обещаются.
- DRM и обфусцированные шрифты остаются неподдерживаемыми.
- Не добавляются выбор движка, резервный старый сборщик, UnMerge и новые параметры CLI.

## Development Approach

- Regular: реализация, затем регрессионные тесты.
- Завершать задачи последовательно; перед следующей задачей весь набор тестов
должен проходить.
- Каждая задача включает новые или обновлённые тесты.
- До переключения CLI сохранять работоспособность прежнего конвейера.
- Переиспользовать проверки ZIP, безопасный XML-парсинг, генерацию имени и атомарную
публикацию.
- Не изменять алгоритм EpubMerge и не исправлять его результат собственным сборщиком.

## Post-Completion

Автоматические проверки подтверждают структуру и сохранность проверяемого
содержимого. Оценка внешнего вида на пользовательской читалке остаётся отдельной
проверкой после реализации. Расширять поддержку несовместимых входов следует по
конкретному образцу и регрессионному тесту.
