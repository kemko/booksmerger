# Один title для названия сборника и файла

## Overview

Удалить --output и поле Command.output. Необязательный --title задаёт название сборника и основу
имени EPUB в текущем каталоге. Без --title сохранить существующий алгоритм generated_title.
Использовать существующий output_filename для безопасного имени файла, включая
ограничение основы до 200 байт UTF-8. Внутри EPUB сохранять полное название после
существующего удаления крайних пробелов. --title не становится путём к файлу.

## Context

- src/bookmerger/cli.py: аргументы, Command, выбор пути, проверки и атомарная публикация.
- src/bookmerger/collection.py: generated_title и использование названия внутри EPUB; изменения не нужны.
- tests/test_cli.py, tests/test_pipeline.py: проверки интерфейса и сборки.
- tests/test_epub_preservation.py, tests/test_review_regressions.py, tests/test_second_review_regressions.py, tests/test_fourth_review_regressions.py,
tests/test_fifth_review_regressions.py, tests/test_sixth_review_regressions.py: вызовы Command, требующие обновления.
- README.md, AGENTS.md, tests/test_readme_example.py: документация и исполняемые примеры.
- Новые зависимости и компоненты не нужны.

## Development Approach

- Regular: реализация, затем тесты.
- Завершать каждую задачу полностью; все тесты должны проходить перед следующей.
- Каждая задача включает новые или обновлённые тесты.
- Сохранить generated_title, output_filename, защиту существующих файлов и атомарную публикацию.
- Удалить старый интерфейс без совместимого псевдонима --output.
